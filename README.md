# RotationScale-TemplateTracker

**中文名称：** 基于旋转与多尺度模板匹配的目标跟踪器

**完整描述：** 基于 OpenCV 的多尺度、旋转自适应模板匹配方法，用于视频目标检测、关键点定位，并通过自适应局部重新匹配实现跨帧位置跳变修正。

## 项目介绍与工作原理

### 项目概述

本项目基于 OpenCV，实现了一套结合多尺度、旋转自适应模板匹配与自适应跨帧跳变修正的视频目标检测及关键点定位流程。

算法主要包含以下五个阶段：

### 1. 模板库生成

通过对参考模板进行不同角度的旋转和不同尺度的缩放，生成包含多种旋转角度及尺寸的模板库，使算法能够检测视频中处于不同方向和尺寸的目标。

### 2. 多特征模板匹配

结合灰度图像与 Canny 边缘特征，利用加权归一化互相关方法，对视频每一帧进行模板匹配，定位候选目标。

随后，通过非极大值抑制（NMS）去除重叠检测结果，保留有效的目标检测框。

### 3. 关键点定位

利用 Shi–Tomasi 角点检测算法，在参考模板中自动提取特征点。

支持交互式关键点选择以及手动指定关键点坐标。

根据检测目标的位置、缩放比例与旋转角度，对选定关键点进行对应的几何变换，从而确定其在当前视频帧中的位置。

### 4. 跨帧位置跳变修正

对相邻视频帧中的检测结果进行关联，并识别检测框位置是否出现异常跳变。

当检测到位置跳变时，算法首先根据上一帧与当前帧的检测框构建联合搜索区域。

随后，在该区域内进行迭代式模板重新匹配，并结合以下策略寻找满足跨帧位置连续性要求的候选检测结果：

- 对局部搜索区域进行随机扰动与逐轮扩张。
- 逐步增加每轮匹配允许保留的候选目标数量。
- 根据匹配置信度及跨帧位置变化阈值，筛选符合要求的检测结果。

通过上述方法，尝试恢复在时间维度上保持位置连续性的目标检测结果，减少异常跳变。

### 5. 视频可视化

在视频帧中绘制目标检测框、匹配置信度、目标旋转角度、缩放比例以及选定的关键点。

最终将标注后的所有视频帧合成为视频文件并导出。

本项目采用传统计算机视觉技术，无需神经网络训练，也不依赖预训练模型权重。
